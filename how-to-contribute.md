# How to Contribute to this Website

GitHub tracks contributions, which means that contributors must first be logged in to a GitHub account, free at the basic level. Contributions can be made to wikis, discussions, and the contents of repositories.

  Wikis are public paged documents that contributors can edit directly. ABSEL's wiki is attached to the .github repository. The standard path to the wiki is from the **Repositories** menu item of [ABSEL Store](https://github.com/abselstore) to [.github](https://github.com/abselstore/.github). To access, bring up [ABSEL Store wiki](https://github.com/abselstore/.github/wiki). Then click the **New page** button at the top right of the page to add a page, or click one of the links of the sidebar on the right to bring up an existing wiki page.
  
  Discussions are public chats that also are attached to the .github repository. The standard path to discussions is from the  **Discussions** menu item of [ABSEL Store](https://github.com/abselstore). To access, bring up [ABSEL Store discussions](https://github.com/orgs/abselstore/discussions). Then either click the **New discussion** button at the top right of the page to start a new discussion or click one of the listed discussions to join it. To comment on a discussion topic, in the discussion page that appears, type your comment into the **Add a comment** edit box, then click the **Commit** button to submit it. Submission accepted, the comment appears, to which others might reply. To change your committed comment or reply, click the three-dot (...) menu to the right of the item and select the desired change: edit, hide, or delete.

  Repositories are containers for files. Everyone with a GitHub account can create and edit the contents of a personal repository, but only privileged members can do likewise for an organizational repository. Those not privileged to create an ABSEL Store repository but who nevertheless have products for the ABSEL Store can contribute by creating a personal public-template repository as a template and offering the repository for inclusion following the instructions in [Submitting Digital Materials for the ABSEL Store](https://github.com/abselstore/.github/blob/main/submit-materials.md).  
  
  To create a repository for the ABSEL Store, from the [ABSEL Store](https://github.com/abselstore), click the **Repositories** menu item. A list of the store's repositories will appear and, if you are privileged to create a repository for the ABSEL Store, a **New repository** button will appear on upper right of the area. Click that button. Then fill in the repository creation form that appears and click the **Create repository** button on the bottom of the form. Repository created, you can proceed to put files into the repository by clicking, in the **Quick setup** box that appears, the link to *creating a new file* or *uploading an existing file*. 

  Changing the contents of a repository by one who did not create the repository requires action by the requester asking for the change and the repository's collaborators, as explained in [How to Request Changes to Repository Contents](https://github.com/abselstore/.github/blob/main/request-changes.md).

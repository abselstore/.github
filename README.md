# Instructions for Contributors

GitHub, [free at the basic level](https://github.com/pricing), with [special services for educators](https://github.com/education), has many features that support storing and sharing. It also has [interactive courses for learning about its features](https://learn.github.com/skills), including [Introduction to GitHub](https://github.com/skills/introduction-to-github), a course for beginners. Even so, the single-page instructions listed here should sufficient for contributors who want to get things done quickly.

## Table of Contents

1. README.md: This introductory message.
2. how-to-contribute.md: General instructions on how to contribute to wikis, discussions, and contents of repositories.
3. request-changes.md: Detailed instructions on how to request changes to the contents of repositories.
4. submit-materials.md: Detailed instructions on how to submit materials.
